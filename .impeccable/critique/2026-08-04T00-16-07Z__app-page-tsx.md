# Critique: Lodestone "Today" page (app/page.tsx)

Method: dual-agent (A: design review · B: detector/browser evidence). Note: mid-run, Assessment B's live-server overlay bled into Assessment A's browser tab via the shared localhost:3000 origin — a process isolation gap, not a data integrity one. Assessment A explicitly did not use the leaked overlay labels and re-derived its contrast findings independently from source + manual WCAG math before cross-referencing. Treated as reliable; flagged here per protocol.

## Design Health Score: 22/40 — Acceptable, undercut by an unresolved data bug and competing hero cards

## Design Specificity Verdict
Mixed. Base palette ("Eucalyptus") is explicitly modeled on Headspace-style wellness-app convention in its own code comments — generic at that layer. The brand's actual distinctive asset (nebula/starfield) is reserved for sign-in and celebration states and does not appear on Today, the screen used daily. Underneath, the state-morphing hero, DayArc, and nudge-compression logic are genuinely authored for this product's premise.

## What's Working
1. State-aware hero: four distinct treatments driven by check-in/wrap/time-of-day, peak-end-rule reasoning documented in source.
2. Nudge compression: one full card + a chip row for the rest — correctly-applied progressive disclosure.
3. Copy voice: warm, specific, never templated SaaS-speak.

## Priority Issues

**[P0] Duplicate calendar events render as self-conflicting entries.** Same "Work" event ×3 and "Gym" event ×2 shown as separate, independently-completable rows, each flagged with a conflict warning against its own duplicate. Undermines the product's lead differentiator (calendar-aware, conflict-avoiding). Fix: dedupe by source event ID before render; audit lib/schedule.ts's conflict grouping. → /impeccable harden

**[P1] Page opens on an alarm, not a greeting.** "⚠ 2 conflicts" renders top-right in warn-orange before any calming copy is processed — works directly against the "calm, low-stimulation" product principle. Fix: move below the hero or restyle as neutral until severity is known. → /impeccable quieter

**[P1] Repeated "side-tab" card styling — 6 instances, the detector's single most-flagged AI-interface tell.** Every schedule-row card (colored left-border + rounded corner) matches this pattern. Detector: 6/19 total findings on this page. → /impeccable layout or /impeccable typeset

**[P1] Contrast failures on primary text — 8 instances.** Hero check-in heading and "Your coach is ready" heading (#6fa588 on #2a3830, ~4.3:1) plus 6× "done?" buttons (#94a096 on #313b33, ~4.3:1) sit under the 4.5:1 AA minimum for their weight/size. Confirmed independently by both assessments. → /impeccable harden

**[P2] "Your coach is ready" card visually duplicates the hero's weight.** Identical background/padding/heading treatment directly beneath the state-driven hero, defeating the "one clear next step" intent. → /impeccable clarify

## Persona Red Flags
- **Jordan (first-timer)**: unexplained alarm badge + 3 visually-identical "conflicting" Work blocks reads as the app being broken.
- **Casey (distracted mobile user)**: fastest actions (Quick log, Quick-tick) sit after two full-width cards + a 6-row list; nav overflow has no scroll affordance at the 375px primary viewport.
- **Priya (burned-out streaker, project persona)**: GoalCard's "Behind pace" status reuses the exact same warn-orange/triangle vocabulary as the real conflict badge — shared visual grammar reads as shame-adjacent despite soft copy, for exactly the user this product claims not to alarm.

## Minor Observations
- AnimatedBar animates CSS `width` directly (layout-triggering) rather than `transform: scaleX()` — 3 instances; real but low-severity given one-shot fills, not continuous animation.
- Single font family (Geist, 100% of text) flagged by detector as a slop-adjacent pattern, but this reads as a deliberate consistent choice rather than a generic-AI-default tell — low confidence finding.
- Nav overflow ("Areas" tab off-screen at 375px, no fade/affordance) — real discoverability gap, not severe enough for the top-5 cut.

## Questions
- Should the conflict badge exist as a standing header alarm at all, or should conflict-avoidance live silently inside the suggestion logic per the brand promise?
- Should "Your coach is ready" only show as a full card once (first unlock), then collapse to a small persistent icon?
- Is the nebula/starfield identity being deliberately withheld from Today, or has this screen just not been revisited since sign-in/celebration got that treatment?
